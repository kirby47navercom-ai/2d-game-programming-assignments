## 실행

각 과제 폴더를 작업 디렉터리로 열어서 실행하세요. 이미지·음원 등 상대 경로를 유지하려면 저장소 루트가 아니라 해당 과제 폴더 안에서 실행해야 해요. 과제별 Python 코드와 기존 리소스는 수정하지 않았어요. 실행에 필요한 Python과 pico2d 등은 과제 코드에 맞게 별도로 준비하세요.

## 기록 보존

원본 기본 브랜치의 커밋 기록을 통합 브랜치의 부모 기록으로 보존했어요. 원본의 모든 브랜치는 `history/<원본 저장소>/<원본 브랜치>`에 보존했어요. `SOURCE_REPOSITORIES.json`에서 원본 URL과 가져온 커밋을 확인할 수 있어요. `2DGP-DRILL-01`과 `2DGP-DRILL1`은 서로 다른 과제 파일이므로 별도 폴더로 유지했어요. 번호가 없는 과제는 새로 만들지 않았어요.

원본 저장소 18개는 통합과 보존 검증 후 삭제했어요. 위 기록 링크는 통합 저장소 안에 보존한 원본 커밋을 열어요. `SOURCE_REPOSITORIES.json`의 원본 URL은 이전 위치를 기록한 이력 정보예요.
